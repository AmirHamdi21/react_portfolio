# Archived design directions — DO NOT delete

These are the two runner-up directions from the Phase 2 evaluation of the
October 2026 portfolio redesign. **"The Instrument" (direction B) was chosen**
as the canonical design — see `../MASTER.md`.

They are kept as self-contained, working HTML mockups (open directly in a
browser; each includes a working dark-mode toggle).

| File | Direction | Revive it if… |
|---|---|---|
| `direction-A-the-dossier.html` | Editorial Grid + Exaggerated Minimalism — print-dossier aesthetic, Libre Bodoni + Public Sans, ultramarine `#0B5CFF` on paper `#FCFCFA` | The site shifts to a more conservative, recruiter-first editorial tone; a long-form "writer's" identity is ever wanted |
| `direction-C-the-poster.html` | Bauhaus constructivism — Outfit 900, hard 4px offset shadows, poster primaries (red `#E62D2D` / blue `#103FC0` / mustard `#F0B905`), mechanical press interactions | A bolder, louder identity is wanted for a personal-brand push distinct from recruiting |

Any future resurrection of these directions must re-run the anti-slop
self-critique from the `frontend-design` skill — especially A, whose
cream-neutral territory drifts toward the "AI editorial" tell.
